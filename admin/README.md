# аромазон-тут / admin

Внутренняя админка для аромазон-тут — управление заказами и переводом/видимостью
товаров. Vite + React + TypeScript, отдельный репозиторий/деплой от `web/`.

## Запуск

```bash
npm install
cp .env.example .env   # VITE_API_URL по умолчанию указывает на localhost:4000
npm run dev             # http://localhost:5173
```

Бэкенд — `api/` (Fastify), должен быть запущен отдельно (`npm run dev` там же, порт 4000).
CORS на бэкенде настраивается через `ADMIN_ORIGIN` в `api/.env` (по умолчанию
`http://localhost:5173`).

## Первый вход

Публичной регистрации нет — админ-аккаунты создаются вручную:

```bash
cd ../api
npm run seed:admin -- you@example.com "СтройныйПароль123"
```

При первом входе после ввода пароля откроется экран настройки 2FA (QR-код для
Google Authenticator / Яндекс.Ключ) — без подтверждённого кода вход не завершится.

## Структура

- `src/auth/` — вход (пароль → 2FA), защищённый роут
- `src/orders/` — список заказов (поиск/фильтр по статусу), карточка заказа
- `src/products/` — список товаров (поиск/фильтр «без перевода»), редактирование
  перевода и видимости (`hidden`)
- `src/lib/api.ts` — fetch-клиент с `credentials: "include"`
