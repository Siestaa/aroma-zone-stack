# Почта Unisender Go

Сервис отправляет письма покупателю при оформлении заказа, изменении статуса,
добавлении или замене трек-ссылки, запросе восстановления и смене пароля.
Адрес `CONTACT_EMAIL` получает обращения из формы контактов, новые заказы
и уведомления о том, что покупатель отметил оплату.

## Настройка отправителя

В аккаунте Unisender Go добавьте домен отправителя `email.аромазон.рф` и перенесите в DNS Beget
записи SPF и DKIM, показанные сервисом. Дождитесь успешной проверки домена.
Публичный адрес витрины — `https://xn--80aavshcdl.xn--p1ai`.

В `/var/www/aroma-zone/api/.env` заполните следующие значения.

```dotenv
UNISENDER_API_KEY=ключ_из_аккаунта_Unisender_Go
UNISENDER_API_URL=https://go2.unisender.ru/ru/transactional/api/v1
EMAIL_FROM=no-reply@email.xn--80aavshcdl.xn--p1ai
EMAIL_FROM_NAME=Аромазон-тут
EMAIL_REPLY_TO=aromazone.tut@gmail.com
CONTACT_EMAIL=aromazone.tut@gmail.com
PUBLIC_WEB_URL=https://xn--80aavshcdl.xn--p1ai
```

В `EMAIL_FROM` укажите адрес на подтверждённом домене. `EMAIL_REPLY_TO`
и `CONTACT_EMAIL` должны указывать на действующие ящики, которые вы читаете.
Unisender Go обеспечивает исходящие письма. Для получения ответов используйте
свой почтовый ящик и его MX-записи. Значения SPF сверяйте с текущими настройками
почтового провайдера и инструкциями Unisender.

Ключ относится к Unisender Go, API которого описан в
[официальном справочнике](https://godocs.unisender.ru/web-api-ref).

## Выкладка

На VPS под пользователем `aromazone` выполните команды после заполнения `.env`.

```bash
cd /var/www/aroma-zone &&
git pull --ff-only &&
npm --prefix api ci &&
npm --prefix api run build &&
env -u DATABASE_URL npm --prefix api run db:migrate &&
npm --prefix web ci &&
npm --prefix web run build &&
sudo systemctl restart aroma-zone-api aroma-zone-web
```

Для миграции требуется новая таблица очереди, токенов и ограничений запросов.
Заказы и письма сохраняются в одной транзакции. Очередь обрабатывается внутри API
каждые 30 секунд. После ошибок выполняется до восьми попыток с увеличением
интервала. Письма хранятся до 24 часов, ссылки восстановления — до 30 минут.
После приёма письма Unisender запись из очереди удаляется. Доставку в ящик
проверяйте в журнале Unisender Go.

При отсутствии `UNISENDER_API_KEY` или `EMAIL_FROM` очередь приостанавливается.
Формы восстановления и контактов в этом случае показывают временную недоступность.

## Проверка

1. Войдите на витрину через «Забыли пароль» с email существующего покупателя.
   Дождитесь письма, откройте ссылку и сохраните новый пароль.
2. Повторное применение ссылки должно завершиться сообщением о недействительной
   ссылке. Старый пароль и предыдущие сессии перестают работать.
3. Оформите тестовый заказ, подтвердите оплату в админке и добавьте трек-ссылку.
   Проверьте письма покупателю и на `CONTACT_EMAIL`.
4. Отправьте сообщение через «Контакты». На `CONTACT_EMAIL` придёт письмо,
   ответ на которое адресуется отправителю обращения.

Ошибки повторных попыток видны в `journalctl -u aroma-zone-api`.
В PostgreSQL сводку очереди можно получить запросом без чтения содержимого писем.

```sql
SELECT attempts, count(*) FROM email_outbox GROUP BY attempts ORDER BY attempts;
```

Для восстановления пароля используется одноразовая случайная ссылка со сроком
30 минут. Токен в таблице восстановления хранится в виде SHA-256.
Ссылка в ожидающем письме доступна до отправки или истечения срока.
Фрагмент ссылки не передаётся в access-log сервера, а страница восстановления
использует `no-referrer`. Повторный запрос заменяет предыдущую ссылку.
Восстановление доступно для покупателей на витрине.
